## ✅ Problem Statement (F1)

**Challenge:** Design a personal finance application that analyzes income and spending and provides actionable budgeting insights. The system should identify recurring expenses, spending patterns and opportunities to improve savings.

**Key Features (MVP):**
1. **Income & Expense Tracking** — Add/view income and expenses with categories
2. **AI-Powered Insights** — Rule-based categorization, recurring expense detection, savings tips
3. **Budget & Savings Goals** — Set budgets, track spending vs limits, savings goals

**Scope beyond MVP (if time permits):**
- Monthly/yearly financial summary
- Exportable reports
- Notification alerts for overspending
- Multi-currency support
